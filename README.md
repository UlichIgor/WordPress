## Що додано до репозиторію

### 1. Повніша класична PHP-тема

Тема тепер має окремі шаблони для основних сценаріїв WordPress:

| Файл | Призначення |
|---|---|
| `style.css` | Заголовок теми та адаптивні стилі |
| `functions.php` | Налаштування теми, меню, логотип, мініатюри та підключення ресурсів |
| `header.php` | HTML-head, навігація, hero-блок головної сторінки |
| `footer.php` | Контакти, меню підвалу, `wp_footer()` |
| `index.php` | Резервний шаблон і список записів |
| `page.php` | Окрема сторінка |
| `single.php` | Окремий запис |
| `archive.php` | Архів записів |
| `search.php` | Результати пошуку |
| `404.php` | Сторінка не знайденої адреси |
| `comments.php` | Коментарі та форма коментування |
| `assets/js/theme.js` | Доступне мобільне меню |

### 2. Можливості теми

- Підтримка автоматичного заголовка документа через `title-tag`.
- Підтримка логотипа сайту.
- Підтримка зображень записів і власного розміру мініатюр.
- Головне меню та меню у підвалі.
- HTML5-сумісна розмітка.
- Підключення CSS/JS через WordPress enqueue API.
- Адаптивна сітка карток і мобільна навігація.
- Посилання переходу до основного вмісту та ARIA-стан меню.
- Обробка ситуацій, коли ACF-поля порожні або плагін ACF не встановлений.
- Шаблони сторінок, записів, архіву, пошуку та 404.

### 3. Інтерактивний курс — 12 модулів

1. Старт: що таке WordPress і тема.
2. Структура теми та ієрархія шаблонів.
3. Каркас сторінки: header, footer і хуки.
4. functions.php: підтримка теми та хуки.
5. Підключення CSS і JavaScript.
6. The Loop: записи, сторінки та пагінація.
7. Advanced Custom Fields (ACF).
8. Меню, логотип і зображення записів.
9. Адаптивність і доступність.
10. Безпека, SEO та продуктивність.
11. Налагодження, тестування та публікація.
12. Фінальний проєкт: власний сайт на WordPress.

Курс містить пояснення, приклади PHP-коду з кнопками копіювання, практичні чеклісти, мінітести після модулів, інтерактивний симулятор ієрархії шаблонів, лабораторію екранування тексту та підсумковий іспит із 12 питань. Для успішного іспиту потрібно набрати щонайменше 10/12. Прогрес зберігається у localStorage браузера.

## Як запустити PHP-тему

1. Підготуй тестову інсталяцію WordPress на локальному комп'ютері або хостингу з PHP і базою даних.
2. Скопіюй файли теми до `wp-content/themes/wordpress-learning-theme/`.
3. Увійди в адмін-панель → **Зовнішній вигляд → Теми**.
4. Активуй **WordPress Learning Theme**.
5. Створи записи й сторінки, додай зображення записів.
6. Відкрий **Зовнішній вигляд → Меню**, створи меню та признач його місцю «Головне меню».
7. За потреби встанови ACF і налаштуй поля за [довідником ACF](./docs/ACF-FIELDS.md).

Повна інструкція: [docs/START-HERE.md](./docs/START-HERE.md).

## GitHub Pages: що саме публікується

GitHub Pages публікує лише статичний навчальний курс із директорії `course/`. Він не виконує PHP, не запускає WordPress і не підключається до бази даних. Для запуску теми потрібен справжній WordPress-сервер.

Workflow: `.github/workflows/deploy-course.yml`. Він автоматично публікує курс після змін у `course/**` або ручного запуску в GitHub Actions. У налаштуваннях репозиторію **Settings → Pages → Build and deployment → Source** має бути вибрано **GitHub Actions**.

## Важливо перед production

Це навчальна основа, а не готовий до продажу універсальний шаблон. Перевір тему на конкретній версії WordPress/PHP і з потрібними плагінами. Зроби аудит безпеки, доступності й продуктивності, резервну копію та тестування на staging-середовищі перед оновленням реального сайту.
