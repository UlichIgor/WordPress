# Початок роботи з темою WordPress

Цей репозиторій містить навчальну класичну PHP-тему WordPress і окремий інтерактивний курс. Тема та курс мають різні способи запуску.

## 1. Що потрібно встановити

- PHP версії, яку підтримує ваша версія WordPress (перевіряйте вимоги на офіційному сайті WordPress).
- WordPress на локальному або тестовому сервері.
- Вебсервер і база даних (наприклад, локальне середовище Local, XAMPP або Docker).
- Редактор коду (наприклад, Visual Studio Code).
- За потреби — плагін Advanced Custom Fields (ACF).

> GitHub Pages не виконує PHP. На GitHub Pages відкривається лише статичний навчальний курс із папки `course/`, а не PHP-тема.

## 2. Встановлення теми

1. Завантажте репозиторій як ZIP або скопіюйте його через Git.
2. Переконайтеся, що файли `style.css`, `functions.php`, `index.php`, `header.php` і `footer.php` лежать в одному корені теми.
3. Скопіюйте папку теми до `wp-content/themes/wordpress-learning-theme/`.
4. Увійдіть в адмін-панель WordPress.
5. Відкрийте **Зовнішній вигляд → Теми** та активуйте тему.
6. Відкрийте сайт у новій вкладці та перевірте головну сторінку.

## 3. Налаштуйте сайт після активації

- **Зовнішній вигляд → Налаштувати** або редактор сайту: додайте логотип, якщо ця функція доступна у вашій версії WordPress.
- **Зовнішній вигляд → Меню**: створіть меню та призначте його місцю «Головне меню» або «Меню у підвалі».
- **Записи → Додати запис**: створіть кілька тестових записів, додайте зображення запису та категорії.
- **Сторінки**: створіть сторінки «Про нас», «Послуги», «Контакти».
- **Налаштування → Читання**: за потреби встановіть статичну головну сторінку.
- **Налаштування → Постійні посилання**: оберіть зрозумілу структуру URL та збережіть налаштування.

## 4. ACF — додаткові поля

Тема не створює групи полів ACF автоматично. Якщо використовуєте ACF, встановіть плагін і створіть групу полів із ключами, наведеними в [довіднику ACF](./ACF-FIELDS.md). Якщо ACF не встановлено, тема використовує безпечні резервні значення для окремих полів.

## 5. Як перевірити результат

- Перегляньте головну сторінку, окремий запис, сторінку, архів, пошук і неіснуючу адресу.
- Перевірте меню на телефоні.
- Додайте зображення запису та перевірте картку.
- Перевірте сайт з порожніми ACF-полями.
- Перевірте PHP-журнал і консоль браузера.
- Перевірте, що всі URL працюють після зміни постійних посилань.

## 6. Навчальний курс

Відкрийте [інтерактивний курс](../course/). Прогрес зберігається локально у браузері. Для продовження навчання використовуйте той самий браузер і профіль.
