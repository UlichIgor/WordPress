# Структура теми: призначення кожного файлу

| Файл | Для чого потрібен |
|---|---|
| `style.css` | Обов'язковий заголовок теми та стилі оформлення. |
| `functions.php` | Реєстрація підтримки теми, меню, розмірів зображень і підключення ресурсів. |
| `header.php` | Початок HTML-документа, метадані, `wp_head()`, шапка й навігація. |
| `footer.php` | Контакти, меню підвалу, `wp_footer()` і закривальні HTML-теги. |
| `index.php` | Резервний шаблон для списків записів та інших запитів. |
| `page.php` | Відображення окремих сторінок WordPress. |
| `single.php` | Відображення окремого запису блогу. |
| `archive.php` | Архіви категорій, тегів, дат та інших архівних запитів. |
| `search.php` | Результати пошуку. |
| `404.php` | Сторінка для URL, яких не існує. |
| `comments.php` | Виведення коментарів і форми коментування. |
| `assets/js/theme.js` | Невелика взаємодія: мобільне меню. |
| `course/` | Статичний навчальний курс; не є частиною PHP-виконання теми. |

## Як WordPress обирає шаблон

WordPress використовує ієрархію шаблонів. Наприклад, для окремого запису система шукає спеціалізований шаблон, а потім переходить до більш загального. Якщо спеціального файлу немає, у класичній темі врешті використовується `index.php`.

Приклади:
- Головна сторінка сайту: `front-page.php`, якщо він існує; інакше діють правила ієрархії.
- Сторінка записів: `home.php`, якщо існує; інакше `index.php`.
- Окремий запис: `single-{post-type}.php`, `single.php`, потім `singular.php`, далі `index.php`.
- Сторінка: `{custom-template}.php`, `page-{slug}.php`, `page-{id}.php`, `page.php`, `singular.php`, `index.php`.
- Архів: спеціалізовані archive-файли, потім `archive.php`, потім `index.php`.
- Пошук: `search.php`, потім `index.php`.
- 404: `404.php`, потім резервна поведінка теми.

Це скорочений навчальний огляд. Повна схема: https://developer.wordpress.org/themes/basics/template-hierarchy/
