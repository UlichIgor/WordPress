# Налаштування Advanced Custom Fields (ACF)

## Важливо

PHP-код із викликом `get_field('field_name')` лише читає поле. Він не створює це поле в адмінці. Потрібно встановити ACF, створити групу полів, задати точні Field Name і призначити групу потрібній сторінці або типу запису.

## Рекомендована група «Налаштування головної сторінки»

| Field Label | Field Name | Тип | Призначення |
|---|---|---|---|
| Фонове зображення шапки | `header__bg` | Image | Фонове зображення hero-секції. Для зручності оберіть Return Format: Image URL або врахуйте, що тема підтримує масив з URL. |
| Назва в шапці | `header__name` | Text | Короткий підзаголовок під основним заголовком. |
| Заголовок у шапці | `header__title` | Text | Основний заголовок першого екрана. |
| Телефон | `phone` | Text | Номер для посилання `tel:`. |
| Заголовок головного блоку | `main-title` | Text | Може використовуватись у власних блоках сторінки. |
| Текст головного блоку | `main__text` | WYSIWYG або Textarea | Опис головного блоку. |
| Заголовок галереї | `gallery__title` | Text | Заголовок галереї. |
| Текст галереї | `gallery__text` | Textarea | Опис галереї. |
| Вміст галереї | `gallery__inner` | WYSIWYG або Gallery | Вміст або розмітка галереї. |
| Email підвалу | `footer__email` | Email | Контактний email у підвалі. |

## Призначення групи

Для полів шапки оберіть Location Rule: **Page is equal to** потрібна головна сторінка, якщо ви хочете редагувати значення саме на ній. Якщо поля мають бути глобальними для всього сайту, використовуйте ACF Options Page (ця функція може вимагати відповідної версії/додаткового рішення) або інший механізм глобальних налаштувань.

## Типові помилки

1. Field Name має бути точним: `header__title` і `header_title` — різні ключі.
2. Поле створене, але група не прив'язана до сторінки.
3. Поле Image повертає ID або масив, а шаблон очікує URL. Перевірте Return Format.
4. Значення залишено порожнім. Додайте резервний текст або зображення.
5. Не виводьте довільний HTML із поля без перевірки. Для звичайного тексту використовуйте `esc_html()`, для URL — `esc_url()`, для дозволеного форматованого HTML — `wp_kses_post()`.
