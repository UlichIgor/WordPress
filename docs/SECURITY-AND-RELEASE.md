# Безпека, доступність і випуск теми

## Безпечне виведення

Екранування обирають за контекстом:
- `esc_html( $value )` — звичайний текст усередині HTML.
- `esc_attr( $value )` — значення атрибута.
- `esc_url( $url )` — URL у `href` та `src`.
- `wp_kses_post( $html )` — HTML, дозволений для вмісту запису.

Перевіряйте та очищуйте дані під час їх збереження, а екрануйте під час виведення. Не вставляйте паролі, ключі API, дампи бази даних або файли конфігурації з секретами у відкритий GitHub.

## Доступність

- Додавайте змістовний alt до інформативних зображень.
- Для декоративних зображень використовуйте порожній alt.
- Забезпечуйте видимий фокус клавіатури.
- Використовуйте правильну ієрархію заголовків.
- Для меню та кнопок задавайте зрозумілі назви й ARIA-стани.
- Перевіряйте контраст тексту та роботу без миші.

## Продуктивність

- Завантажуйте тільки ті CSS/JS, які реально використовуються.
- Не додавайте бібліотеки лише «про всяк випадок».
- Використовуйте оптимізовані зображення та відповідні розміри мініатюр.
- Уникайте запитів до бази даних усередині циклів без потреби.
- Перевіряйте кешування на рівні хостингу та плагінів.

## Перед релізом

- [ ] Тема активується без PHP-помилок.
- [ ] Головна, сторінка, запис, архів, пошук і 404 відображаються.
- [ ] Меню призначене до потрібного місця.
- [ ] Логотип і мініатюри працюють.
- [ ] Порожні та заповнені поля ACF не ламають макет.
- [ ] Перевірено мобільну ширину й клавіатурну навігацію.
- [ ] Немає битих шляхів до CSS, JS та зображень.
- [ ] Немає секретів у репозиторії.
- [ ] Зроблено резервну копію сайту перед оновленням теми.

## Межі цього репозиторію

Це навчальна класична тема, а не готовий до продажу універсальний шаблон. Перед використанням у production потрібні перевірка на конкретній версії WordPress/PHP, тестування з потрібними плагінами, аудит доступності, безпеки та продуктивності.
